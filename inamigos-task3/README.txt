INAMIGOS FOUNDATION — TASK 3
Professional AI Website Generation Submission

WHAT THIS IS
A responsive, production-style nonprofit website concept created for the InAmigos Foundation Task 3 submission.

DESIGN DIRECTION
The visual system takes cues from mature nonprofit/corporate digital products: strong editorial hierarchy, restrained color, large photography, clear impact metrics, structured programs, partnership pathways and prominent but non-aggressive calls to action.

FEATURES
- Responsive desktop/tablet/mobile layout
- Sticky navigation + mobile menu
- Animated impact counters
- Six program cards
- Donation intent modal with amount selection
- Volunteer application modal
- Contact form
- LocalStorage persistence for demo submissions
- Accessible labels, focus states, skip link and semantic sections
- Smooth scrolling and subtle interaction states
- No framework/build step required

IMPORTANT
The donation flow is a UI/demo flow only. It does NOT process real payments. To accept real donations, connect the form to a verified payment provider/backend.

RUN
1. Extract the ZIP.
2. Open index.html in a modern browser, OR run a local server (recommended).
3. All CSS and JavaScript are local. Photography is loaded from Unsplash over the internet.

SOURCE CONTEXT
Content about InAmigos Foundation's initiatives, credentials and contact details is based on its public website. Visual inspiration follows common nonprofit/corporate UX patterns; no third-party branding or copyrighted layouts are copied.
